사용 방법

  1. 카메라를 달 쪽으로 맞춰 주세요
  2. 두 손가락으로 확대/축소해 달의 크기를 조정하세요 (주의: 달이 크게 보인다고 항상 더 좋은 것은 아니며, 너무 많이 확대하면 화질이 떨어질 수 있습니다)
  3. 달을 탭하면 자동으로 초점이 맞춰집니다. 자동 초점이 충분히 선명하지 않다면 초점 슬라이더를 드래그해 수동으로 맞추세요
  4. '-'와 '+' 버튼을 탭해 밝기를 조절하세요. 밝기를 낮추면 달의 디테일을 더 많이 살릴 수 있습니다
  5. 원형 셔터 버튼을 탭해 사진을 찍으세요
